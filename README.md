# 🚦 Semáforo Inclusivo e Acessível

Projeto desenvolvido para a disciplina utilizando a metodologia ágil **Scrum**. O sistema consiste em uma aplicação web interativa que simula um semáforo com recursos de acessibilidade para deficientes visuais, daltônicos, idosos e pessoas com mobilidade reduzida.

🔗 **Link do Projeto Rodando:** [Acesse aqui](https://SEU-USUARIO.github.io/semaforo-acessivel/)

## ♿ Recursos de Acessibilidade Implementados

* **Deficientes Visuais:** Leitura por voz (Web Speech API) anunciando cada troca de sinal.
* **Daltônicos:** Símbolos visuais (❌, ⚠️, ✔) dentro das luzes do semáforo e botão de **Alto Contraste**.
* **Idosos e Mobilidade Reduzida:** Botão para solicitar tempo extra na travessia (+8 segundos).
